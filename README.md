# Readance Android (unofficial)

A minimal Android WebView wrapper for https://readance.app/. Independently made; **not affiliated with Readance**.

- Android 7.0+ (API 24).
- Runs first-party pages in WebView.
- Opens third-party links and downloads in the user's browser.
- JavaScript, cookies and local storage enabled to preserve original website behavior.
- Android system back navigates in-app history.
- Build: Android Gradle Plugin 8.7.3, Gradle 8.10.2, Java 17, compile SDK 35.
- GitHub Actions produces debug-signed installable APK for personal testing.

No remote APIs beyond the website are added. This is not the official app. Account login and payment, if any, remain the website's.
